# WAP V4 天气预测交易实时监控台 · 使用说明

> 版本：4.0.0-alpha.1｜更新：2026-08-06
> 访问：`http://<服务器>:8784`（本地）或 GitHub Pages 公开站点（只读快照）
> 运行模式：**PAPER_ONLY（纸面模拟）** —— 系统只生成纸面决策与计划，不提交任何真实订单。

---

## 一、这个监控台是什么

监控台统一展示城市资格、天气决策、纸面计划与成交漏斗，回答三个问题：

1. **哪些城市可以参与策略**（城市池资格）
2. **每个城市今天的决策结论是什么**（评估事件、计划、阻断原因）
3. **纸面计划的执行与风控状态**（名额占用、成交率、PnL）

策略价值（预测能力）与执行权限（实盘授权）**始终分开展示**。

## 二、核心概念（先读这段，否则指标会看不懂）

| 概念 | 含义 | 关键点 |
|---|---|---|
| **业务日期** | 监控台按 Asia/Shanghai 划分"今天"，**每日 06:00 翻转** | 页面顶部"业务日期 / YYYY-MM-DD" |
| **合约本地日** | 每份天气合约按**城市当地日期**结算 | 同一"业务日"可能同时出现 08-06 和 08-07 两个合约日 |
| **城市池** | 城市按治理状态分类 | 影子准入=可评估；轻量采集=只观察；规则阻断=排除 |
| **决策窗口** | 每城每天有本地时间窗口 | 正式窗口 **10:30–10:45**（见下节） |
| **策略通过** | 某轮评估中候选符合策略门槛（正边际+中心档） | 名额满后会自动下降，不是异常 |
| **纸面名额** | 当日最多 5 个纸面计划（风险上限 400U），**持久保留** | 生成后不会被后续阻断覆盖 |
| **实盘授权** | 仅当城市为 CASH_ELIGIBLE 且系统处于实盘模式才为 true | 当前恒为 false（PAPER_ONLY） |

### 决策窗口时间轴（每城当地时间）

| 阶段 | 当地时间 | 行为 |
|---|---|---|
| BEFORE_WATCH | 08:30 前 | 等待观察窗口 |
| WATCHING | 08:30–09:00 | 观察中 |
| DECISION_OPEN（早段） | 09:00–10:30 | **只评估观察，不生成正式计划** |
| **TARGET_WINDOW（正式窗口）** | **10:30–10:45** | **唯一生成正式计划、竞争纸面名额的时段** |
| DECISION_OPEN（晚段） | 10:45–11:30 | 不再开新仓 |
| RISK_ONLY | 11:30 后 | 仅风控动作（减仓/退出） |

## 三、顶部 6 个指标卡（口径说明）

| 指标 | 显示内容 | 口径 |
|---|---|---|
| **城市池总数** | 49 | 城市注册表全量城市数；副标题为各池实际分布（影子准入/轻量采集/规则阻断…），**各池加总 = 总数** |
| **今日评估事件** | 74 | 今日业务日内**去重后**的评估记录数（含观察、等待、阻断）；副标题"策略通过 N（最新评估）"= 最新一轮仍符合策略的城市数 |
| **今日生成计划** | 3 | 今日业务日内生成的计划记录数；副标题"台账名额 M / 5"= **持久化占用**的纸面名额（跨业务日生成的计划也会计入台账，因此两者可不等） |
| **完整成交率** | x% | 完整成交单数 ÷ 提交单数；副标题为成交/提交明细 |
| **当前开放风险** | xx U | 今日未了结纸面计划的风险敞口；副标题为今日成交额 |
| **今日已实现 PnL** | ±xx U | 仅**已确认执行事件**计入，不含纸面假设 |

> 常见疑问："为什么名额 4 个但策略通过只有 1？"
> 因为名额是**持久保留**的（生成时已锁），而"策略通过"统计的是**此刻**最新一轮评估——名额满了之后，后续重估会被 `CORRELATION_GROUP_RISK_LIMIT` 等风控挡住，策略通过数自然下降。两者口径不同，不是数据错误。

## 四、面板逐块说明

### 1. 标准纸面决策名额（顶部面板）
- 展示当日名额目录（最多 5 个），按**合约本地日**分组
- 已分配名额显示：城市、档位、计划仓位、实际风险、决策/计划 ID
- 已分配的名额**不会**被后续阻断重估覆盖

### 2. 当日决策执行漏斗
- 五级漏斗：决策重估 → 策略通过 → 生成计划 → 提交执行 → 完整成交
- 每级显示阶段转化率；仅统计今日业务日

### 3. 城市池分布
- 各池数量条形图（完整采集/轻量采集/影子准入/…）
- 底部下拉框可筛选城市列表

### 4. 城市分类与分析（主表格）
每行一座城市，列含义：

| 列 | 含义 |
|---|---|
| 城市 | 中文名 + city_id |
| 资格池 | 影子准入/轻量采集/规则阻断… |
| 站点/时区 | 结算站 + 本地时区 |
| 相关组 | 风险相关组 |
| 今日决策 | 评估次数｜通过数 · 计划数 |
| 最新状态 | 治理标签 + **窗口标签**（如"正式决策窗口"/"决策打开(非正式)"）+ 运营状态 + 阻断原因 + 下次检查时间 |

### 5. 城市详情（点击任意城市行）
- 基础信息：结算站、时区、时区组、气候子类
- **决策窗口**：当前阶段 + 正式窗口时间（本地 10:30–10:45）
- 纸面风控：子类名额、全局名额、风险占用
- 晋级证据：时间点完整率、盘口完整率、模型技能、校准质量
- 名额状态：是否已预留、当前阻断

### 6. 当日决策表
- 今日业务日内每条评估的：时间、城市/合约日、决策类型、动作与档位、概率/包价、预期净 ROI、权限（策略/实盘双灯）、首要原因

### 7. 可执行订单
- 已生成计划的执行详情：仓位、方式、各腿委托价与股数、到期时间

### 8. 分析面板（底部三块）
- 决策结果分布、执行单状态、主要阻断原因（Top8）

## 六、状态码速查

| 状态/阻断 | 含义 | 解除方式 |
|---|---|---|
| 正式决策窗口 | 正在 10:30–10:45 目标窗口 | — |
| 决策打开(非正式) | 09:00–10:30 或 10:45–11:30，不生成计划 | 等正式窗口/次日 |
| CORRELATION_GROUP_RISK_LIMIT | 相关组风险额度已满 | 该组风险释放或次日重置 |
| CLIMATE_SUBCATEGORY_DAILY_PLAN_LIMIT | 气候子类当日已有一个计划 | 次日重置 |
| DAILY_PACKAGE_COUNT_LIMIT / DAILY_NEW_RISK_LIMIT | 当日名额（5）或风险（400U）已满 | 次日重置 |
| WEATHER_DATA_STALE / MARKET_BOOK_STALE | 天气/盘口超龄 | 等待新快照 |
| CITY_NOT_SHADOW_ELIGIBLE | 城市仅采集未获策略准入 | 完成冻结前瞻验证 |
| CITY_BLOCKED_RULE | 结算站/合约规则未获治理批准 | 规则复核 |

## 七、安全边界（重要）

1. 系统恒为 **PAPER_ONLY**，顶部显示"实盘关闭"；实盘授权恒为 false
2. 纸面名额、PnL 均为**模拟**，不代表真实账户回报
3. 页面只读，不提供任何下单操作
4. 城市池分类与决策时间由治理配置控制，页面不修改
